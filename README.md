## 🚀 About The Project

This is a responsive, modern, and dark-themed portfolio website built to display data analysis projects, analytical skills, professional experience, and certifications.

### Key Features
- ⚡ **Clean & Modern UI:** Responsive dark mode layout.
- 📈 **Interactive Projects Section:** Includes a lightbox viewer for project visualizations.
- 📱 **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- 📬 **Direct Contact:** Quick links for LinkedIn, GitHub, Email, and WhatsApp.
